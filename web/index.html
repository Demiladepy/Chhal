// the one idea //

Most teams submit three things. We submit the loop between them.

The brief says it twice: the best solutions turn their own simulated attacks into the training ground for a stronger defense. So Chhal isn’t an attack deck, a generator and a classifier sitting apart — it’s one loop, structured on the challenge’s own three phases, where each half makes the other stronger.

01 — IDENTIFY

Invent

A taxonomy of where GenAI changes payment fraud. Six vectors are built as live code — threshold-hugging, synthetic bust-out, card-testing, a UPI scam, mule fan-out, and an autopay-mandate hijack.

02 — GENERATE

Simulate

Attacks are mounted as timed campaigns on real accounts, then sharpened against the current model without leaving the executable manifold. Fidelity is measured, not asserted.

03 — DEFEND

Retrain

LightGBM learns what it caught; a fixed benchmark it never trains on measures whether it generalizes. Reported at a false-positive budget — then the loop turns again.

// a static model is a fixed target //

Trained once on yesterday’s fraud, a classifier is a puzzle an LLM solves offline.

Chhal makes the target move — and reports the hard parts too.

Static detector

  • ✕ Catches almost none of the adaptive attacks — they’re tuned to look normal.
  • ✕ Every gap it leaves is stable, so an attacker finds it once and reuses it.
  • ✕ “Realistic” attacks are asserted, never measured against real traffic.
  • ✕ Gains on training data can be memorisation — no proof it generalizes.

Chhal · closed loop

  • ✓ Recall climbs from 0% to 80.8% at a 0.1% FP budget, on attacks never trained on — and the run verifies it honoured that budget (0.0998% realised).
  • ✓ Each gap the red team finds becomes the next training signal — the target moves.
  • ✓ Fidelity is a number: on-manifold 100%, mimicry KS 0.175 versus real traffic.
  • ✓ On a family held out entirely: 43.1% — reported, not hidden. Honest generalisation.

// the money chart //

Two honest lines, kept separate.

Benchmark — the money line.

A fixed set of hard adaptive attacks, built once and never trained on. A static model catches almost none of it. The loop pulls it up and holds — generalisation, not memory.

Pressure — the honest gap.

Each iteration the red team optimises a fresh batch against the current model and holds it out. It stays volatile: the attacker keeps finding evasions. The gap is the arms race, unfinished.

“Isn’t this circular — you attack your own model, retrain, and of course it improves?”

// fixed benchmarkHard attacks built once against the baseline and never trained on. Improving on them is generalisation to unseen fraud.
// held-out familyLeave a whole attack family out of training and the model catches 43.1% of it — versus 66.1% on trained families. We report the gap, not hide it.
// no leakageThe base split is temporal and frozen before any attack is injected. Benchmark and pressure attacks touch neither.
// the gap is the pointBlue holds the known shape; red keeps probing new ones. We show an arms race, not a solved problem.
